================================================================================
                                PA1_Toggle 工程说明
================================================================================
功能：PA1 高低电平切换，高 500ms / 低 500ms，周期 1s
芯片：PY32F002B（TSSOP20 开发板）
时钟：HSI 24MHz，SysTick 1ms 中断维护全局毫秒时钟 sys

目录：
  MDK-ARM/   Keil 工程（Project.uvprojx）
  Inc/       头文件
  Src/       源文件（main.c / global.c / bsp_pa1.c ...）
  README.md  详细文档

使用方法：
  1. Keil 打开 MDK-ARM/Project.uvprojx；
  2. 安装 Puya PY32F0xx DFP 1.2.15；
  3. 编译下载后观察 PA1：高 500ms -> 低 500ms 循环。

修改周期：改 Inc/main.h 中的 TOGGLE_HALF_PERIOD_MS。

版本：V1.0 (2026-08-18) 首次创建
================================================================================
