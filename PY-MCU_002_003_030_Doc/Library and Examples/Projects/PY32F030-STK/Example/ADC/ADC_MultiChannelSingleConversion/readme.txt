================================================================================
                                样例使用说明
================================================================================
功能描述：
此样例演示了ADC单次轮询(Polling)的方式经行采样AN0,AN1,AN4通道

================================================================================
测试环境：
测试用板：PY32F030_STK
MDK版本： 5.28
IAR版本： 9.20
================================================================================
使用步骤：
1. 给AN0(PA0),AN1(PA1),AN4(PA4)固定电压
2. 运行程序,在仿真界面观察adc_value[0],adc_value[1],adc_value[2]里的值是否正确
