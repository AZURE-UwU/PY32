芯片：PY32F003F18P6TU（TSSOP20，64KB Flash / 8KB SRAM，最高 32MHz）

外设与引脚：
显示屏：
  SPI1 -> （SCK=PA1, MOSI=PA2, DC=PA3, CS=PF1, RST=PF4）
  TIM14-> CH1(PF0)=背光 PWM 无级调光, 10kHz


传感器：
  I2C1 -> INA226（SCL=PB6, SDA=PB7, 100kHz, 地址 0x40）
  ADC1  -> IN5(PA5)=VCC 分压
  ADC1  -> IN4(PA4)=NTC 分压】

外设：
  TIM3 -> CH2(PB5)=风扇 PWM, 10kHz
  GPIO -> SW_WKUP(PA12), SW_FUNC(PA6), SW_MODE(PA7)，高电平有效
  PA0  -> 电源使能（推挽输出，上电高 / 关机低；V0.5 起由板上 LED 脚复用）

按键（V0.2 起统一）
  UP   (SW_WKUP/PA12)  主界面长按关机 ／ 菜单上移 ／ 值编辑 +步长
  SET  (SW_FUNC/PA6)   主界面短按进设置 ／ 切换勾选或进入编辑 ／ 确认
  DOWN (SW_MODE/PA7)   主界面无功能 ／ 菜单下移 ／ 值编辑 -步长
  （菜单与值编辑支持长按连跳：前 2 秒 200ms/步，2 秒后 50ms/步）
