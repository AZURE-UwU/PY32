================================================================================
                                样例使用说明
================================================================================
功能描述：
此样例演示了TIM1和TIM3同步触发（复位触发模式）功能，TIM1作为主机，配置复位TRGO
输出(TIM1_CR2.MMS=000)，TIM3作为从机并且使能事件更新中断，配置收到主机的TRGO信
号后复位(TIM3_SMCR.SMS=100)，仿真模式下查看TIM3会清空CNT的值，然后从0开始重新
计数，不会产生更新中断，LED不会翻转

================================================================================
测试环境：
测试用板：PY32F030_STK
MDK版本： 5.28
IAR版本： 9.20
================================================================================
使用步骤：
1. 下载程序并在debug模式下运行；
2. 查看TIM3的CNT寄存器，当TIM1触发溢出事件时，TIM3_CNT会重新开始计数
