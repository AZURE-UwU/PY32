================================================================================
                                样例使用说明
================================================================================
功能描述：
此样例演示了在TIM1中使用DMA burst传输数据的功能，burst传输一次更新三个寄存器，
PSC,ARR,RCR，在更新事件中断中，PA0会进行翻转，通过逻辑分析仪监测，可看到PA0的
翻转间隔会从第一次400ms，第二次400ms，第三次及后续变为10ms，此时PCS,ARR,RCR
均更新完毕。
================================================================================
测试环境：
测试用板：PY32F003_STK
MDK版本： 5.28
IAR版本： 9.20
================================================================================
使用步骤：
1. 下载并运行程序
2. 通过逻辑分析仪示波器捕捉PA0上翻转间隔
3. 翻转间隔从400ms，变为10ms
4. 变为20ms后，翻转间隔均为10ms
